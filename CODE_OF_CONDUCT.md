# Code Of Conduct

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but accept corrections when impact differs from intent.
- Keep technical disagreements focused on evidence, tradeoffs, and maintainable
  outcomes.
- Respect project boundaries around security reports, private data, and
  unpublished roadmap details.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private security details before maintainers have had a chance to
  respond.
- Sharing secrets, private repository data, or confidential user data.
- Repeatedly derailing issues or pull requests after maintainers have made a
  scope decision.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; reject
contributions; or block participants when behavior harms the project or its
community.

If you need to report conduct concerns, contact the maintainers through a
private channel when available. If no private channel is available, open a
minimal public issue asking maintainers to establish one, without disclosing
sensitive personal or security details.
