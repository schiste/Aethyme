## Competitive Landscape

### Market Leaders

#### 1. Sourcegraph
**Position:** Market leader
**Founded:** 2013
**Funding:** $225M (Series D)
**Valuation:** $2.6B (2021)
**Customers:** 1.8M developers, Uber, Cloudflare, Reddit

**Strengths:**
- ✅ Enterprise-proven (10+ years)
- ✅ Large customer base
- ✅ Self-hosted option
- ✅ Advanced code intelligence
- ✅ Strong brand recognition

**Weaknesses:**
- ❌ Complex setup and configuration
- ❌ Expensive ($10K-100K+/year)
- ❌ Legacy architecture (2013 tech)
- ❌ Poor UX (developer feedback)
- ❌ No AI integration focus
- ❌ GitHub-centric (limited multi-platform)

**Pricing:**
- **Free:** Public repos only
- **Team:** $99/user/month (min 10 users = $990/mo)
- **Enterprise:** Custom ($100K+/year typical)

**Our Advantage:**
- 🎯 **Price:** 1/3 the cost ($29-199/mo vs $990+/mo)
- 🎯 **AI-first:** Claude, Copilot, Cursor integration
- 🎯 **Modern UX:** Built for 2025, not 2013
- 🎯 **Multi-platform:** GitHub + GitLab + Bitbucket
- 🎯 **Graph-based:** Relationships, not just search

#### 2. GitHub Code Search
**Position:** Built-in advantage
**Owner:** Microsoft (acquired 2018 for $7.5B)
**Users:** 100M+ developers

**Strengths:**
- ✅ Built into GitHub (zero setup)
- ✅ Free for GitHub users
- ✅ Massive scale
- ✅ Integration with GitHub features
- ✅ Fast and reliable

**Weaknesses:**
- ❌ GitHub only (no GitLab, Bitbucket)
- ❌ Basic search capabilities
- ❌ No graph/relationship analysis
- ❌ No AI integration
- ❌ Limited to public repos (private requires subscription)
- ❌ No cross-repo insights

**Pricing:**
- **Free:** Public repos
- **Pro:** $4/month (includes private repo search)
- **Team:** $4/user/month
- **Enterprise:** $21/user/month

**Our Advantage:**
- 🎯 **Multi-platform:** Works across all Git hosts
- 🎯 **Graph analysis:** See relationships and dependencies
- 🎯 **AI integration:** Not just search, understanding
- 🎯 **Advanced features:** Code ownership, analytics, collaboration

## Positioning Strategy

### Primary Positioning
**"Sourcegraph for AI-powered development teams"**

### Key Differentiators

#### 1. AI-First (vs. Search-First)
**Sourcegraph:** Built for code search in 2013
**RepoGraph:** Built for AI-assisted development in 2025

**Value Prop:**
- Claude that knows your entire codebase
- Copilot with company code context
- Cursor with cross-repo understanding

#### 2. Graph-Based (vs. Text-Based)
**Competitors:** Text search with basic symbol resolution
**RepoGraph:** Full code knowledge graph

**Value Prop:**
- "What breaks if I change this function?"
- "Show me the call hierarchy across all repos"
- "Find all code paths that lead to this bug"

#### 3. Modern UX (vs. Legacy Tools)
**Sourcegraph/OpenGrok:** Enterprise software from 2005-2013
**RepoGraph:** Consumer-grade UX from 2025

**Value Prop:**
- Cmd+K everywhere
- Beautiful, fast interface
- Zero learning curve
- Mobile-friendly

#### 4. Multi-Platform (vs. Single Platform)
**GitHub/GitLab:** Locked to their platform
**RepoGraph:** Works with all Git hosts

**Value Prop:**
- Search GitHub + GitLab + Bitbucket simultaneously
- Migrate platforms without losing search
- Multi-cloud teams supported

#### 5. Price (vs. Enterprise Pricing)
**Sourcegraph Team:** $990/month (10 users minimum)
**RepoGraph Team:** $199/month (20 users included)

**Value Prop:**
- 1/5 the cost for more users
- Startup-friendly pricing
- No minimum seats

## Competitive Response Playbook

### If Sourcegraph drops prices
**Response:** Emphasize AI-first features and modern UX
- "Sourcegraph is for search. RepoGraph is for understanding."
- Highlight Claude/Cursor integration
- Show UX comparison videos

### If GitHub enhances Code Search
**Response:** Multi-platform advantage
- "Search all your repos, not just GitHub"

## Win/Loss Analysis Framework

### Why Customers Choose Us (Wins)
1. **Better UX** - "Feels like a modern product"
2. **AI Integration** - "Copilot actually useful now"
3. **Price** - "1/5 the cost of Sourcegraph"

## Market Trends

### 1. AI-Assisted Development (🔥 Tailwind)
**Opportunity:** We're positioned perfectly
- Cursor usage growing 500% year-over-year
- Every developer will use AI tools by 2026
- Context quality determines AI output quality

**Strategy:** Become the context layer for AI coding

### 2. Consolidation of Dev Tools (🌊 Headwind)
**Threat:** GitHub/GitLab add everything
- GitHub acquiring more tools (npm, Dependabot, Copilot)
- GitLab "single application" strategy

**Strategy:** Better integrations, multi-platform lock-in prevention

### 3. Remote Work & Multi-Repo Teams (🔥 Tailwind)
**Opportunity:** Code spread across more repos
- Average company has 100+ repos (vs. 10 in 2015)
- Microservices = more fragmentation
- Need to search across all

**Strategy:** Excel at multi-repo search and analysis

### 4. Security & Compliance (🔥 Tailwind)
**Opportunity:** Enterprises need code governance
- SOC 2 required for enterprise sales
- GDPR/data residency for EU
- Audit logging for compliance

**Strategy:** Enterprise security as differentiator

## Our Moat (Defensibility)

### Short-Term (0-12 months)
- **Speed to market** - MVP in 2 months vs. years for competitors
- **Modern tech stack** - Latest frameworks vs. legacy
- **Focus** - Doing one thing well vs. feature bloat

### Medium-Term (1-3 years)
- **AI integrations** - Deep partnerships with Claude, Cursor
- **Graph database** - Proprietary code graph is hard to replicate
- **Customer data** - Usage patterns improve AI suggestions
- **Network effects** - More users = better training data

### Long-Term (3-5 years)
- **Brand** - "RepoGraph" = code search (like "Google" = web search)
- **Switching costs** - Teams rely on saved searches, annotations
- **Ecosystem** - IDE plugins, integrations, 3rd party tools
- **Data moat** - Billions of code relationships indexed
