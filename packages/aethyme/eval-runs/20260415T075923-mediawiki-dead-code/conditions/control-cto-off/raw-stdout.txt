## Methods Excluded from Results

The following categories of methods were examined but excluded from the unused list:

### Interface Methods
- `WatchedItemStoreInterface::*` - All methods are interface signatures, not implementations
- `WatchedItemQueryServiceExtension::*` - Interface for hook implementations
- `WatchedItemQueryServiceExtensionsHook::*` - Hook interface (deprecated)

### Interface Implementations
Methods like `duplicateEntry()`, `resetNotificationTimestamp()`, etc. in `WatchedItemStore` and `NoWriteWatchedItemStore` implement the `WatchedItemStoreInterface` contract. Although some may not be called externally in the current codebase, they must exist to satisfy the interface contract and cannot be considered "unused" as they're required by the type system.

### Methods with Internal Callers Outside Their Own Class
- `WatchlistLabelStore::countAllForUser()` - Called internally from `save()` method, which is itself called from `SpecialWatchlistLabels::displaySection()`
- `WatchlistManager::isTempWatchedIgnoringRights()` - Called internally from `isTempWatched()`, which is called from `SkinTemplate.php`
- `WatchlistManager::removeWatchIgnoringRights()` - Called internally from `removeWatch()`, which is called from multiple external locations

These are not considered "unused" because they're indirectly accessed through external calls to their callers.

## Methodology

1. **File Enumeration:** Found 15 PHP files in `includes/Watchlist/`
2. **Method Extraction:** Used regex pattern `public\s+(?:static\s+)?function\s+(\w+)\s*\(` to extract all public methods
3. **Exclusions:** Constructors (`__construct`, `__destruct`) and magic methods excluded
4. **Call Site Search:** Used grep with patterns:
   - `->methodName\(` for instance method calls
   - `::methodName\(` for static method calls
   - Additional flexible patterns for method chaining and variable references
5. **Scope Filtering:** Excluded `tests/`, `vendor/` directories from search results
6. **Cross-referencing:** Verified results by checking both direct calls and indirect calls through public APIs

## Recommendations

While the two unused methods identified are rare, they could be considered for removal or documentation:

1. **ClearUserWatchlistJob::newForUser** - Consider if this is intended as a public API for extensions. If not, consider making it private or evaluating why it exists separate from the constructor.

2. **WatchedItemStore::overrideDeferredUpdatesAddCallableUpdateCallback** - This appears to be a testing utility. Consider moving to a test-only class or clearly documenting its testing-only purpose.
