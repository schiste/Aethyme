# Unused Public Methods Analysis - includes/Watchlist/

## Summary
After a comprehensive analysis of all PHP files in `includes/Watchlist/`, I identified **1 unused public method** that is never called from outside the `includes/Watchlist/` directory.

## Methodology
1. Identified all PHP files in `includes/Watchlist/` (15 files)
2. Extracted all public method definitions (excluding constructors and destructors)
3. For each public method, searched the entire codebase outside `includes/Watchlist/` for call sites
4. Excluded test files (`tests/`) and vendor files (`vendor/`) from the caller search
5. Verified findings with multiple grep patterns

## Unused Methods

### 1. overrideDeferredUpdatesAddCallableUpdateCallback()

**File:** `includes/Watchlist/WatchedItemStore.php` (line 180)

**Full Signature:**
```php
public function overrideDeferredUpdatesAddCallableUpdateCallback( callable $callback ): ScopedCallback
```

**Why it's unused:**
- Searched for all occurrences of `overrideDeferredUpdatesAddCallableUpdateCallback` across the entire codebase
- Only 1 match found: the definition in `includes/Watchlist/WatchedItemStore.php` at line 180
- No calls from outside `includes/Watchlist/` (excluding tests)
- The method has a `#[\NoDiscard]` attribute and includes a check `if ( !defined( 'MW_PHPUNIT_TEST' ) )`, indicating it's intended only for testing
- This is a testing-only method that is never actually called from the codebase

**Search verification:**
```
grep -r "overrideDeferredUpdatesAddCallableUpdateCallback" --exclude-dir=vendor | grep -v "tests/"
Result: 1 occurrence (only the definition)
```
