# Unused Public Methods Analysis - includes/Watchlist/

## Executive Summary

After a comprehensive analysis of all PHP files in `includes/Watchlist/`, I found **1 unused public method** that is never called from outside that directory in production code.

---

## Unused Public Methods

### 1. WatchedItemStore::overrideDeferredUpdatesAddCallableUpdateCallback()

**File:** `includes/Watchlist/WatchedItemStore.php`  
**Line:** 180  
**Signature:** `public function overrideDeferredUpdatesAddCallableUpdateCallback( callable $callback ): ScopedCallback`

**Why it's unused:**
- Searched entire codebase (excluding `tests/` and `vendor/`) for calls to this method
- Method is only referenced in test files:
  - `tests/phpunit/unit/includes/Watchlist/WatchedItemStoreUnitTest.php` (5 calls)
  - `tests/phpunit/includes/Watchlist/WatchedItemStoreIntegrationTest.php` (1 call)
- No calls found in production code outside of `includes/Watchlist/`
- The method is documented with comments indicating it's "intended for use while testing"
- Throws `LogicException` if `MW_PHPUNIT_TEST` is not defined, confirming test-only intent

**Search queries performed:**
- `grep -r "overrideDeferredUpdatesAddCallableUpdateCallback" --include="*.php" | grep -v "tests/" | grep -v "vendor/"`
  - Result: Only found in `includes/Watchlist/WatchedItemStore.php` (definition only)

## Methodology

1. **Extracted all public methods** from each PHP file in `includes/Watchlist/`
2. **Excluded constructors and destructors** (`__construct`, `__destruct`)
3. **Searched for each method** using:
   - `grep -r "methodName" --include="*.php" | grep -v "tests/" | grep -v "vendor/"`
4. **Analyzed interface implementations** - Methods implementing interfaces are considered used
5. **Checked Job class methods** - Parent class methods override are considered used (called by job system)
6. **Verified trait methods** - Methods in traits are used by classes that use the trait

---

## Conclusion

Only **1 unused public method** was found:
- `WatchedItemStore::overrideDeferredUpdatesAddCallableUpdateCallback()`

This method appears to be a testing utility that was left as public even though it has explicit logic to prevent usage in production (throws exception if `MW_PHPUNIT_TEST` is not defined). It's reasonable to either keep it for future testing needs or remove it if no longer needed.
