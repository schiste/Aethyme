## 3. Discrepancies and follow-ups

1. **#213 is stale:** Rust and TS `Calls` and explicit non-code `Documents`/`References`/`Tests` edges have landed (2026-10-02 to 10-08). Rust method calls and PHP calls are still absent.
2. **Lossy conversion:** `Tests` (and Implements, Inherits, …) collapse to `References` at `map.rs:1287–1296`, so newly emitted `Tests` edges cannot drive the impact `tests` set precisely. Relevant to #213 and #685.
3. **`producer_version` is never checked on read** (`overlay.rs:155`). The drift detection the module documents is not enforced. Relevant to D47 and #655.
4. **Two ID spaces** (schema NodeId vs engine path-string model IDs for file/dir/doc/config/area/repo). #652/#655 must state which one a portable `SymbolRef` wraps; D39.
5. **No test of NodeId body-independence** (T65 baseline); add one when #652 starts.
6. **The session guard lives only in the CLI layer** (`graph_refresh.rs`). Direct `aethyme-graph-storage::disk` writes bypass it; X2 must not.
7. **The source-tree digest is over Git object ids**, not raw bytes. Do not conflate it with #652's `SourceSnapshotId`.
8. **No SCIP code, and no Rust SCIP notes**; X1 starts from scratch.
9. Manifest/freshness use bare `git` from PATH (`manifest.rs:89`, `lifecycle.rs:33`): known PATH-shim sensitivity.
