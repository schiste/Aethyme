## 7. Known Limitations

### 1. Link Conversion Accuracy
- **Limitation:** Requires target files to exist for accurate relative path calculation
- **Impact:** Some absolute links may not convert
- **Workaround:** Dry-run shows which links will be converted
- **Severity:** LOW

### 2. Selector Name Uniqueness
- **Limitation:** Multiple similar elements may get similar selector names
- **Impact:** Potential selector collisions in complex components
- **Workaround:** Names include file and attribute context
- **Severity:** MEDIUM

### 3. i18n Framework Support
- **Limitation:** Only React i18next and Django gettext supported
- **Impact:** Other frameworks require manual implementation
- **Workaround:** Documented; can be extended
- **Severity:** MEDIUM

### 4. Formatter Dependencies
- **Limitation:** Format fixer requires external formatters installed
- **Impact:** Skips files if formatter not available
- **Workaround:** Clear error messages; formatter detection
- **Severity:** LOW

### 5. Large Repository Performance
- **Limitation:** Processing 10,000+ files may exceed 5s target
- **Impact:** Slower on massive repos
- **Workaround:** Use specific fix types; process subdirectories
- **Severity:** LOW

### 6. PR Creation Requirements
- **Limitation:** Requires clean working tree and gh CLI
- **Impact:** Cannot create PR if uncommitted changes
- **Workaround:** Clear error with instructions
- **Severity:** LOW

### 7. Concurrent Execution
- **Limitation:** Not thread-safe; run sequentially
- **Impact:** Cannot parallelize fixes
- **Workaround:** Fast enough for single-threaded use
- **Severity:** LOW

### 8. Generated File Detection
- **Limitation:** Some edge cases may not be detected
- **Impact:** Could accidentally modify generated file
- **Workaround:** 40+ patterns + header detection
- **Severity:** LOW (well-mitigated)
