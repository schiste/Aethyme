# Agent Instructions

Generated by Aethyme; do not edit. Customize `.aethyme/overrides/agents.json`
(policy) or `.aethyme/overrides/onboarding.json` (orientation), then run
`aethyme deploy --repo "$PWD"`.

## Finding code

For "where is X" questions, try `aethyme explore --request "<question>" --format brief`
first: one call prints a ranked summary and the top verified source spans. It
is a navigation aid, not an answer. Verify the spans before relying on them.

## Commits

Subject `type(scope): summary`. Types: `fix`, `feat`, `refactor`, `perf`, `test`, `docs`, `build`, `chore`, `revert`.
Substantive commits (`fix`, `feat`, `refactor`, `perf`) need `Problem`, `Decision`, `Rationale` and `Validation` sections; the others may be subject-only.
Check with `aethyme repo lint-commit-message <file>`.

## Everything else

Load the Aethyme skill: `.claude/skills/aethyme/SKILL.md` (Codex:
`.codex/skills/aethyme/SKILL.md`). Its `references/` hold the detail:
`explore.md` (depth, intents, retries), `broker.md` (leases, gates, Git and
GitHub coordination, publication, recovery), `policy.md` (commit format,
branch and review practice, verifying these files), `graph-task.md` and
`dead-code.md`.
