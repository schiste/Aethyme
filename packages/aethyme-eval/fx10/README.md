# FX10 sustained-arrival Playground

This fixture freezes six independently maintained route features and one shared command contract for the Local controller sustained-arrival qualification. The older ready group is A-alpha, B-beta and C-gamma; they form one required atomic unit. D-delta, E-epsilon and F-zeta are later compatible singleton submissions. Every submission changes one feature module, so the same independent behavior oracle applies to both accepted waves.

The contract, source files, per-submission replacement bytes, proxy, oracle vectors and expected transcript are immutable qualification inputs. `proposal-manifest.json` binds their byte digests and the arrival schedule. The actual harness must verify those digests before starting Docker or Git acceptance.

The deterministic arrival observer waits for the exact active wave's fresh native gate job to enter `dispatching`. That gate first contends on a real host-resource capacity lease with a five-second wait bound. The observer queues D-F, confirms A-C remain the exact active wave and the target remains Verifying, then releases only its own lease after 250 ms of measured contention. The report verifies the distinct native gate lease was admitted after release from the same one-unit pool and records its actual wait. The later wave accepts D-F without cancelling or restarting A-C.

A separate bounded negative schedule uses a second disposable target and bare remote. While its exact A-C native job is dispatching behind a typed one-unit capacity hold, the observer advances that remote's accepted ref once with a fast-forward commit that retains the same source tree. It releases the hold after 250 ms; the real verifier must then pass against the now-stale candidate, and the one finite publication attempt must fail safely. The report records actual lease identities, wait and stale-verification intervals, the unchanged competitor ref, and zero private completions or retries. The fixture never injects a completion, verifier result, or provider receipt.
