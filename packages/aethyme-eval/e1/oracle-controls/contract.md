# Independent observer calibration controls (private, UNRUN)
These handcrafted self-tests calibrate only the frozen browser observer. They are not composition examples, candidates, expected merge answers or resolver inputs. Do not expose them to any engine/model selection context. No engine/browser/model trial was run during design.
Invoke each with public requirement selection [search,consent,privacy,navigation]. The positive page has functioning Enter and pointer search, unchanged navigation, initially unchecked consent, no request before consent, exactly one event-only POST to the frozen endpoint per consented search, and no event after revocation. Transport rejection is caught because intercepted telemetry success is not part of functional search.
Each negative preserves those same DOM/search behaviors and changes one independent condition: an event on load before consent, percent-encoded query appended to the URL path, hex-encoded query in a safelisted Accept header, or a WebSocket attempted at load. The socket case must be intercepted/rejected without a real outbound connection; it must not be run without the observer's socket route and outer network-denial boundary.
Expected results: positive passes; early-load fails entire pre-consent-history assertion; percent-path fails exact endpoint/privacy; hex-Accept fails header privacy; WebSocket fails unsupported-network-channel assertion. Numeric exit codes follow the actual observer runner and are not invented here. Preserve every command/log/count, including failed calibration. Never tune candidate behavior using these files.
