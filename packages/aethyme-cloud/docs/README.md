## 📖 What is Aethyme Cloud?

Aethyme Cloud is a graph-based repository analysis and AI-powered code intelligence platform. It provides:

- **Repository Indexing** - Automatic code repository analysis and indexing
- **Graph Analysis** - Relationship and dependency graph visualization
- **AI Integration** - AI-powered code search and insights
- **OAuth Integration** - Secure GitHub/GitLab integration
- **WebSocket Support** - Real-time collaboration features

When adding documentation:

   - `guides/` - How-to guides and tutorials
   - `planning/` - Strategic planning and roadmaps
   - `sessions/` - Meeting notes and session summaries
   - `status-reports/` - Progress reports and status updates

   - Use UPPER_CASE for major documents

   - Include dates for time-sensitive docs
