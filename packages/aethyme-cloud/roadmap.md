# Aethyme Cloud Roadmap

## Goal

Turn the cloud package into a thin, reliable SaaS layer over a stable backend contract.

## Current Position

The package already has broad surface area. The next step is not adding more roadmap phases. The next step is narrowing scope and proving integration.

## Priorities

### 1. Contract Alignment

- decide how cloud depends on the core package
- remove contradictory status and architecture narratives
- make one backend path authoritative

### 2. Minimal Working Flow

Target one verified flow:

- authenticate
- connect or register a repository
- search/query data
- show a basic result in the UI

### 3. Product Fit Cleanup

After the minimal flow works:

- improve repository UX
- improve AI settings and usage surfaces
- add richer graph and scorecard UX only when backed by working APIs

## Non-Priorities

Not first:

- long future-phase enterprise timelines
- speculative compliance claims
- roadmap percentages
- feature catalogs disconnected from current runtime behavior
