# Support

## Community Support

Use GitHub issues for reproducible bugs, documentation gaps, and focused feature
requests in the public support scope.

The initial public support scope is Aethyme Core:

- `packages/aethyme`
- `packages/aethyme/rust`
- root OSS documentation and CI

## Out Of Scope For Community Support

Unless maintainers explicitly move them into public support scope, these areas
are experimental or internal:

- `packages/aethyme-cloud`
- `packages/aethyme-eval-ui`
- private deployment configuration
- unpublished benchmark/eval operations

## Before Opening An Issue

- Check the root README and `packages/aethyme/docs/getting-started/quickstart.md`.
- Include the exact command, operating system, Python version, Rust version, and
  relevant error output.
- Do not include secrets, access tokens, private repository contents, or
  customer data.
