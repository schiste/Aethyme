# Governance

Aethyme is currently maintained by its core maintainers.

## Decision Model

Maintainers make final decisions on:

- public release scope
- security fixes and disclosure timing
- compatibility guarantees
- release timing
- roadmap acceptance

Substantive design changes should be proposed in an issue or pull request before
large implementation work begins.

## Contribution Policy

Unless explicitly stated otherwise, contributions intentionally submitted to
this repository are licensed under Apache-2.0, matching the project license.

The project does not currently require a CLA. Maintainers may introduce a DCO or
CLA later if the contributor model changes.

## Stability Policy

The initial OSS surface is Aethyme Core. Cloud and private deployment
surfaces may change without compatibility guarantees until maintainers publish a
separate stability policy for them.
